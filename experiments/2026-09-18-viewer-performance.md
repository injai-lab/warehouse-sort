# 실시간 관람 성능 개선 — 2026-09-18

## 유지한 실행 조건

새 학습 없음. 최고 EMA 체크포인트 `131f25d665933d4ff5e452c5909b60f56cedc902d6ee45a3fda747afd2401527`, state 입력, DDPM 100회, 예측 16 중 1:9의 행동 8개, 관측 이력 2개, GPU0와 기존 4개 환경을 유지했다. 물리 진행의 기존 최대 20스텝/초 제한도 유지했다. 화면에서 선택한 환경 하나만 전송하며 시뮬레이션 환경 수는 바꾸지 않았다. 시스템/드라이버/프로젝트 패키지 변경 없음.

실제 관람 구현은 PhysX 자세 JSON을 PC로 보내 WebGL로 그리는 방식이다. 서버 카메라 렌더링과 영상 인코딩 단계는 존재하지 않는다. Vulkan 문제 해결과 MP4 인코딩 최적화를 수행한 것이 아니다.

## 측정

서버 시뮬레이션 스레드에서 CUDA 동기화 후 추론/물리 시간을 분리했다. 상태 추출, JSON 직렬화, gzip, 소켓 쓰기도 계측했다. `/profile`의 평균과 p95는 최근 최대 4096건이며 리셋 때 초기화한다. 브라우저는 렌더 호출 간격/CPU 제출시간, 상태 수신시각을 기록한다. 렌더 제출시간은 GPU 작업 완료시간이 아니다. 소켓 쓰기 시간도 원격 수신 완료시간은 아니다.

같은 시범 70스텝 상태와 난수 시드에서 기존 모델을 200스텝 실행했다. Chromium headless SwiftShader, 1280×850 창, DPR 1.5, CDP 요청 지연 100ms/다운로드 256000B/s/업로드 128000B/s 조건이다. 변경 전에는 DPR 1.5, 변경 후에는 기본 균형 품질(렌더 배율 1)을 사용했다. 초기 메시 다운로드 이후 측정했다.

**사용자 PC 및 인증된 VS Code 터널의 실측값은 아니다.** CDP는 지속 SSE 연결의 각 메시지에 매번 요청 지연 100ms를 추가하는 완전한 WAN 에뮬레이터가 아니다. 따라서 아래 개선 폭을 실제 터널에 그대로 적용할 수 없다. 사용자 PC 값은 새 성능 패널에서 확인한다.

지연 표는 각 nonzero 스텝의 **첫 수신**에 대한 수치이며 실제 표시까지의 렌더 대기·보간은 제외한다. 모니터 표시 지연을 44ms로 주장하지 않는다. 표시용 보간은 최대 80ms의 추가 수렴 시간을 둔다. 추론 중에는 같은 자세가 유지되므로 화면의 상태 나이는 약 1초 이상 증가할 수 있다. 전체 프레임의 상태 나이 집계는 기준 측정 시작에 오래된 일시정지 상태가 포함돼 비교 지표에서 제외했다. 원본 측정은 무시 대상인 `runs/viewer-performance/`에 보존했다.

## 구현 변경

- `/stream` SSE 지속 연결: 선택 환경의 최신 상태 하나만 읽어 보냄. 과거 상태 재생 큐 없음.
- 브라우저도 다음 렌더에 쓸 상태 하나만 덮어씀. 독립 requestAnimationFrame 루프에서 화면을 그림. 숨겨진 탭에서는 그리기를 생략.
- 저/균형/고 품질은 렌더 배율·폭 상한, 전송 상한 8/15/20Hz, 표시 좌표 자릿수 3/4/5를 조절. 모델 입력이나 물리 좌표는 반올림하지 않음.
- 80ms 위치/회전 보간을 켜고 끌 수 있음. 에피소드 변경·리셋·정지 때는 해당 실제 자세로 즉시 맞춤. 물리 중간 상태나 미래 행동을 계산하는 기능은 아님.
- 느린 소켓 쓰기 제한 2초, SSE 오류/5초 무수신 시 polling 복구 및 10초 후 재연결. 생성 후 오래 지연된 메시지 감지 시 스트림을 끊고 최신 상태를 요청. OS/프록시 버퍼 자체까지 없애지는 못함.
- 표시 FPS, 새 상태 Hz, RTT, 추정 상태 나이, 추론/물리 평균 패널 추가. PC/서버 시계 차이는 요청 중간시각으로 보정하므로 비대칭 지연 오차가 있음.
- 바인딩 127.0.0.1과 기존 제어 토큰 유지. 공개 포트 없음.

## 별도 선택지 — 이번에는 적용하지 않음

DDPM 횟수를 줄이면 추론 정지가 짧아질 수 있지만 행동과 성공률이 바뀔 수 있다. 행동 묶음 길이 변경, 물리 실행 중 다음 행동을 미리 예측하는 방식도 관측/행동 시점을 바꾼다. 모두 별도 정책 평가가 필요한 선택지이며 이번 변경에는 포함하지 않았다.
