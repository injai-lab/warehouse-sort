# 분류 완료 후 시작 위치 복귀

기존 prepare 실험 모드에 완료 후 복귀를 추가했다. 기존 full/demo70/model70 모드는 유지했다. 새 학습이나 대량 평가는 하지 않았다.

## 동작

- 에피소드 초기 정상 reset 직후 손끝 XYZ를 `home`으로 저장한다.
- 두 상자의 정분류가 확인되면 남은 모델 행동을 버린다. 그 뒤 모델을 재호출하지 않는다.
- 정상 pd_ee_delta_pos 명령으로 집게 열기 → 상승 → 수평 이동 → 시작 손끝 높이로 하강한다.
- 도달 시 `done`으로 자동 정지하고 계속 버튼을 비활성화한다. 실패 시 최대 180스텝에서 중단하고 기록한다.
- 상자/통 초기화와 물리 상태 강제 설정은 없다. 관절 자세 전체가 아닌 초기 손끝 위치 복귀이다.
- 복귀 시간을 확보하기 위해 prepare의 전체 상한만 400에서 600스텝으로 늘렸다. 정상 도달 시 상한 전에 종료한다. 기존 200스텝 평가와 별개이다.

## 왜 준비 이동이 도움이 되었는가

관찰: 이전 모델 단독 실행은 첫 분류 후 두 번째 상자 옆의 빈 공간에 접근했다. 시범 70 상태 복원 실험은 성공했고, 정상 행동으로 준비 위치에 이동한 단일 에피소드도 성공했다. 모델 가중치와 추론 설정은 바꾸지 않았다.

추정: 첫 분류 후 팔·집게·최근 관측이 시범에서 익힌 두 번째 상자 접근 상황과 달라졌고, 준비 이동이 모델이 처리하기 쉬운 상태로 되돌렸을 가능성이 있다. 첫 상자까지 성공해도 다음 상자로 전환하는 접근 행동이 안정적이라는 뜻은 아니다.

단정할 수 없는 점: 이번 개입은 팔 위치, 열린 집게, 최근 관측, 물리 경과시간을 함께 바꾼다. 팔 위치만 원인이라는 통제 실험은 하지 않았다. 시작 위치로 반드시 돌아와야만 성공한다거나 일반적인 성공률이 개선됐다고 확정할 수 없다.

## 왜 마지막에 또 집으려 했는가

이전 실험 루프는 성공 여부와 무관하게 step==400일 때 정지했다. env.step의 종료 반환값을 제어에 사용하지 않았고 환경도 ignore_terminations=True이다. 모델 get_action은 4차원 이동/집게 행동만 반환하며 종료 명령을 반환하지 않는다. 따라서 분류 완료 후에도 남은 행동 및 새 예측 행동을 계속 실행했다.

성공 후 추가 집기 행동의 직접적인 실행 원인은 이 중단 조건 부재이다. 모델의 특정 사후 행동이 왜 선택됐는지에 대한 내부 원인을 따로 확정한 것은 아니다. 현재 prepare 모드에서는 성공 감지 즉시 행동 큐를 버리고 복귀 후 종료한다.
